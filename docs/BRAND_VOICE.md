# PG Cashflow — brand voice

**One sentence:** Every rupee and every room on one ledger tenants, owners, and wardens can trust.

## Pillars

| Pillar | Story                               | UI                                    |
| ------ | ----------------------------------- | ------------------------------------- |
| Ledger | Numbers beat memory; UTR + due code | Owner dues, tenant passbook, CSV      |
| Floor  | Daily ops are real work             | Warden inspections, headcount, meters |
| Flame  | On-time rent is dignity + perks     | Tenant streak, rewards                |
| Gate   | Trust starts at join                | Invite → KYC → owner activation       |

## Voice

- Concrete: “Room 204 · ₹8,500 due 5 Sep”, not “Payment pending”.
- Indian PG: UPI, rupees, warden — not generic property SaaS.
- Three doors, one truth: same due code on pay sheet, ledger, WhatsApp reminder.
- No hype: no “AI-powered” or “revolutionary”.

## GTM arc

Problem (registers + WhatsApp chaos) → Promise (one ledger) → Proof (UTR, inspections, streaks) → Action (invite / sign in).

Public name: **PG Cashflow**. PWA short name: **PG Cashflow**.
